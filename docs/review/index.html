Play the slice

Extract the private ZIP and open DungeonCrawlerCarlemon-N05.gba in a GBA emulator. The tested core is mGBA 0.10.5. Start a fresh save; keep older development saves separately.

  • D-pad moves. A interacts/confirms. B cancels. START opens the menu; save outside battle.
  • Read the entrance note, then visit the Quiet Landing guide and trial. Carl uses STRIKE/BRACE; Donut uses SPARK/WEAKEN.
  • The guide restores health, status and action uses freely. Defeat recovers locally; retry or backtrack.
  • The Service Room's southwest ladder leads to two patrols and the warden. After winning the required fights, examine the northeast stairs.
  • The quest, trap, equipment and cache preparation are optional. BRACE/WEAKEN or the cache preparation route can help with the warden.

What was verified

The final production build passed 90 actual emulator sessions and 1,531 assertions: 1,338 production checks and 193 explicitly labeled diagnostic-fixture checks. All 90 emulator error logs were empty. There are also 38 exact rendered comparisons.

Coverage includes fresh prepared completion, both patrol orders, segmented unprepared victory, all six exact recovered-save wins and cold reloads, quest/reward/crafting branches, old-save compatibility, and blocked collection paths.

Still for human review: pacing and the 20–30 minute target. Scripted waits are not reading or decision time. Prepared uninterrupted completion passes; unprepared wins are verified separately, not claimed as an uninterrupted run.

Remaining placeholders: static poses, stationary Donut, inherited audio and some interface/effect elements. Opening chronology is compressed with original adaptation dialogue. The accepted environment kit has documented source-sheet/packed-output omissions; complete source-sheet reproduction is not claimed.
