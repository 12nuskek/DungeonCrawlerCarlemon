far exit is still closed, and return safely without completing optional content.

  either required branch milestone; visiting Warrens does not require finishing
  the other branch, nor does it complete it.

  Warrens. Keep the ordinary return to Commons available without salvage,
  rewards, a consumable, payment, dialogue completion or a mandatory rematch.
- Reuse the proposed symbolic `WARRENS_RETURN_OPEN` from the
  [Causeway brief](causeway-refuge-scene-brief.md#symbolic-conditions-and-readiness).
  This scene reads it only. After its reviewed D8-side gate interaction, the
  persistent D8 ↔ D7 ↔ D5 passage works in both directions.
- Neither visiting nor skipping Warrens grants or blocks a main milestone.
  Both branch outcomes still precede Pumpworks, actual drainage precedes legal
  Causeway access, and D9 victory/descent remain separate. The optional loop
  cannot bypass those requirements.
