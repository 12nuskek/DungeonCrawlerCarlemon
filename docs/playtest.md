# Playing the development slice

Start with a fresh save. Keep old development saves separately; cross-milestone
compatibility is not promised. This is a private review build, not a public release.

Open the locally built `.gba` file in mGBA. Map the GBA D-pad, A, B and START in
its input settings. Move with the D-pad; A interacts and confirms; B cancels;
START opens the menu. Save outside combat using START → Save. Use the game's
manual saves for the review; emulator savestates are not required.

Read the crate note in the entrance, then reach the Quiet Landing. Speak to the
guide and complete the visible trial. Carl has STRIKE and BRACE; Donut has SPARK
and WEAKEN. Each has an action when able. SPARK has few uses; the guide restores
health, status and action uses freely. Both defeated returns the duo to the
encounter's map without permanent death. You can retry, backtrack or load a save.

The Service Room has Mara, Lev, a marked trap, a secret and a workbench. Its
southwest ladder leads to two patrols and the gate warden. Beat the trial and both
patrols to challenge the warden. The northeast stairs open after victory and lead
to the slice-complete scene. You can save there and return to earlier rooms.

The optional quest, trap, equipment and cache preparation are not required flags
for finishing. If the warden is difficult, read the WIND UP/SLAM warning, try Carl's
BRACE and Donut's WEAKEN, or use the workbench/cache preparation route. Recovery
is free. This prototype deliberately allows retry and keeps earned progress.

Please note confusing instructions, unreadable art/text, unexpected collisions,
soft locks and any reward/save inconsistency. Record the room, last interaction,
whether the game was reloaded, and a screenshot if possible. A human completion
time is useful: the automated25m17s route includes fixed waits and cannot predict
first-player reading or decision time.

This is a compressed original Book1-opening adaptation, not an exact recreation
of chronology. Donut stands in authored scenes rather than following Carl.
Inherited audio, several interface backgrounds/labels and ball effects remain.
Stages beyond this slice wait for your playtest.
